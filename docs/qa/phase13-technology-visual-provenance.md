## Design restrictions

- No third-party logos or brand marks.
- No fake dashboards, analytics, customer portals, code editors, API consoles or KPI charts.
- No people, offices, servers or hardware presented as owned operating evidence.
- No visual is captioned as proof.
- SVGs contain no remote resources or scripts.
- Phase 12 content remains the authority for operating status.
